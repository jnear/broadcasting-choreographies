# Choreographies with Broadcasting Conditionals

A core choreographic language in which conditionals propagate knowledge of
choice by multicasting the guard value, with a mechanized proof that endpoint
projection is a bisimulation.

- `tex/` — the paper (`main.tex`).
- `rocq/` — the Rocq formalization (`make` inside `rocq/` to build; see its README).
